# CU Culture Com (Static Version)

เว็บไซต์หลักสูตรการสื่อสารเชิงวัฒนธรรมเพื่อการท่องเที่ยว
ธีมสีชมพูจุฬาฯ + วิดีโอพื้นหลัง

## วิธีใช้งาน
1. อัปโหลดไฟล์ภาพและวิดีโอทั้งหมดเข้า repo นี้ (จาก zip ที่ได้รับ)
2. ไปที่ Vercel → Import  repo นี้
3. Framework Preset เลือก **Other**
4. Deploy

ไฟล์ที่จำเป็น:
- index.html (มีแล้ว)
- promo_hero.mp4
- ภาพทั้งหมด (.jpg / .png)
- favicon และ logo
