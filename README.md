# cuculturecom-static

เว็บไซต์หลักสูตรอบรมและทัศนศึกษา ภาควิชาการประชาสัมพันธ์ คณะนิเทศศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ | ต้องแก้บ่อยไหม |
|------|--------|----------------|
| `courses.json` | ข้อมูลหลักสูตรและรุ่นทั้งหมด | **แก้บ่อย** |
| `config.json` | เบอร์ติดต่อ เลขบัญชี ประวัติวิทยากร | นานๆ ครั้ง |
| `index.html` | โครงสร้างและหน้าตาเว็บ | แทบไม่ต้องแก้ |
|  root ของ repo | รูปภาพทั้งหมด | เมื่อมีรูปใหม่ |
| `promo_hero.mp4` | วิดีโอพื้นหลังหน้าแรก | แทบไม่ต้องแก้ |

**หัวใจของระบบ** เวลาเปิดรุ่นใหม่ แก้แค่ `courses.json` ไฟล์เดียว ไม่ต้องแตะ `index.html` เลย

## วิธีเพิ่มรุ่นใหม่ในหลักสูตรที่มีอยู่แล้ว

ตัวอย่าง เปิดหลักสูตรวัดวังรุ่นที่ 12 วันที่ 14 ถึง 17 ตุลาคม 2569

**ขั้นที่ 1** เปิดไฟล์ `courses.json` หาหลักสูตรที่ต้องการ สังเกตบรรทัด `"id": "watwang"`

**ขั้นที่ 2** เลื่อนลงมาหาส่วน `"batches": [` ของหลักสูตรนั้น

**ขั้นที่ 3** เพิ่มรุ่นใหม่ต่อท้าย โดย**ใส่เครื่องหมายจุลภาค** หลังปีกกาปิดของรุ่นก่อนหน้า

```json
        {
          "batchNo": 11,
          "batchCode": "วัดวัง-ร11",
          "dates": "16 ถึง 19 กันยายน 2569",
          "dateStart": "2026-09-16",
          "dateEnd": "2026-09-19",
          "dayLabel": "พุธ ถึง เสาร์",
          "time": "10:00 - 17:00 น.",
          "status": "recruiting",
          "note": ""
        },
        {
          "batchNo": 12,
          "batchCode": "วัดวัง-ร12",
          "dates": "14 ถึง 17 ตุลาคม 2569",
          "dateStart": "2026-10-14",
          "dateEnd": "2026-10-17",
          "dayLabel": "พุธ ถึง เสาร์",
          "time": "10:00 - 17:00 น.",
          "status": "recruiting",
          "note": ""
        }
```

**ขั้นที่ 4** บันทึกไฟล์ แล้ว push ขึ้น GitHub เว็บจะอัปเดตเองภายในหนึ่งนาที

## ⚠️ กฎเรื่องวันที่ ห้ามผิด

มีสองฟิลด์ที่ดูคล้ายกันแต่ใช้ปีคนละแบบ

| ฟิลด์ | ใช้ปีอะไร | ตัวอย่าง | ใช้ทำอะไร |
|-------|----------|---------|-----------|
| `dates` | **พ.ศ.** | `"14 ถึง 17 ตุลาคม 2569"` | ข้อความที่คนอ่านเห็นบนเว็บ |
| `dateStart` `dateEnd` | **ค.ศ.** | `"2026-10-14"` | เว็บใช้เรียงลำดับและเช็คว่าผ่านไปหรือยัง |

**พ.ศ. ลบ 543 เท่ากับ ค.ศ.** เช่น 2569 − 543 = 2026

ถ้าใส่ พ.ศ. ในช่อง `dateStart` เว็บจะคิดว่าเป็นปี 2569 ซึ่งอีก 543 ปีข้างหน้า ตารางรุ่นจะเพี้ยนทั้งหมด

## รหัสรุ่น ทำไมสำคัญ

`batchCode` เช่น `วัดวัง-ร10` คือรหัสที่ผู้สมัครต้องแจ้งตอนโอนเงิน

เพราะแต่ละเดือนมีหลายหลักสูตรเปิดพร้อมกัน ถ้าไม่มีรหัส เจ้าหน้าที่จะแยกไม่ออกว่าเงินก้อนไหนเป็นของใคร

**รูปแบบ** `รหัสหลักสูตร-รXX` โดย `รหัสหลักสูตร` คือค่าในฟิลด์ `code` และ `XX` คือเลขรุ่น

รหัสนี้จะแสดงบนเว็บอัตโนมัติทั้งในตารางรุ่นและบนการ์ดหลักสูตร

---

## สถานะหลักสูตร

ฟิลด์ `status` มีได้ 4 ค่า มีผลต่อสีป้ายและลำดับการแสดง

| ค่า | ป้ายที่แสดง | สี | ใช้เมื่อไหร่ |
|-----|-----------|-----|------------|
| `recruiting` | กำลังรับสมัคร | เขียว | มีรุ่นเปิดรับอยู่ตอนนี้ |
| `upcoming` | เปิดรับเร็วๆ นี้ | ส้ม | จะเปิด แต่ยังไม่ประกาศวัน |
| `ongoing` | จัดเป็นประจำ | ชมพู | จัดสม่ำเสมอ แต่รุ่นถัดไปยังไม่กำหนดวัน |
| `completed` | จัดเสร็จสิ้นแล้ว | เทา | จัดจบแล้ว ไม่เปิดอีก |

**หมายเหตุ** หลักสูตรที่เป็น `completed` จะยังแสดงบนเว็บ แต่ทำสีจางและไม่มีปุ่มสมัคร เก็บไว้เพื่อแสดงว่าเราจัดมาแล้วหลายครั้ง ช่วยสร้างความน่าเชื่อถือ

## วิธีเพิ่มหลักสูตรใหม่ทั้งหลักสูตร

คัดลอกบล็อกของหลักสูตรที่คล้ายกันที่สุด แล้วแก้ค่าทุกฟิลด์ อย่าลืม

- `id` ต้องไม่ซ้ำกับหลักสูตรอื่น ใช้ภาษาอังกฤษตัวเล็ก ไม่มีช่องว่าง
- `code` ต้องไม่ซ้ำ ใช้ภาษาไทยสั้นๆ
- `image` ชี้ไปยังไฟล์ใน  root ของ repo ถ้ายังไม่มีรูป เว็บจะใช้รูปสำรองให้อัตโนมัติ
- ชื่อหลักสูตรใน `title` ควรมีคำว่า **การสื่อสาร** เพื่อสะท้อนจุดยืนของคณะนิเทศศาสตร์

## เช็คก่อน push ทุกครั้ง

เปิด https://jsonlint.com วางเนื้อหา `courses.json` ทั้งไฟล์ กดตรวจ

ถ้าขึ้น Valid JSON แปลว่าใช้ได้ ถ้าขึ้นแดง แปลว่าลืมจุลภาคหรือปีกกา ให้แก้ก่อน push

**ข้อผิดพลาดที่พบบ่อยที่สุด** ลืมใส่จุลภาคคั่นระหว่างบล็อก หรือใส่จุลภาคเกินหลังบล็อกสุดท้าย

---

## การ deploy

เว็บนี้ต่อกับ Vercel ไว้แล้ว เมื่อ push ขึ้น GitHub branch หลัก Vercel จะ build และขึ้นเว็บใหม่ให้เองภายในหนึ่งนาที ไม่ต้องทำอะไรเพิ่ม

## รายการรูปที่ต้องมี

| ไฟล์ | ใช้ที่ไหน |
|------|----------|
| `placeholder.svg` | รูปสำรอง มีอยู่แล้ว |
| `hero-fallback.jpg` | พื้นหลังหน้าแรกบนมือถือ |
| `expert-suriyawut.jpg` | รูปวิทยากร |
| `og-image.jpg` | รูปตอนแชร์ลิงก์ ขนาด 1200 × 630 |
| `course-*.jpg` | รูปแต่ละหลักสูตร ขนาด 1200 × 675 |

ทุกรูปควรมีขนาดไฟล์ไม่เกิน 200 KB เพราะผู้ใช้ส่วนใหญ่เปิดจากมือถือ

หากยังไม่มีรูปใด เว็บจะแสดงรูปสำรองแทนโดยอัตโนมัติ ไม่พัง
